## 🛠️ Deployment Guide (VPS)

<details>
<summary><b>View All Steps</b> <code>Click Here</code></summary>
<br>

1. Clone the repo: `git clone https://github.com/At4fn-Yoo/Nefta-Kpx`
2. Install dependencies: `pip3 install -r requirements.txt`
3. Setup `config.py` or `config.env`
4. Run the bot: `bash start.sh`
</details>
